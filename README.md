# Análisis de incendios forestales (avance 3)

Estadísticas descriptivas, indicadores automatizados y gráficos con Pandas, NumPy y Matplotlib.

## Cómo ejecutar
```
py -m pip install -r requirements.txt
py main.py
```
Desde la raíz del proyecto.

## Estructura
- `datos/procesados/dataset_limpio.csv`: datos de entrada (ya limpios)
- `src/estadisticas.py`: estadísticas descriptivas
- `src/indicadores.py`: indicadores del proyecto
- `src/visualizaciones.py`: gráficos
- `main.py`: ejecuta todo el proceso
- `resultados/`: `estadisticas.csv`, `indicadores.csv` y `graficos/` (se generan al ejecutar)
- `reportes/avance_3.pdf`: informe
